Getting started

When Qute starts, it reopens the files you had open last time. If there are none, it opens an empty Untitled tab. The window has a menu bar, a toolbar, a tab area for your documents, and a status bar.

The toolbar holds shortcuts for New, Open, Open in Follow mode, Save, Save As, Print, Find / Replace, Zoom In, Zoom Out and Preferences. On its right side it shows the language of the current file, the Outline drop-down, the Qute logo and the version number.

When you close a tab or quit with unsaved changes, Qute asks whether to Save, Discard or Cancel. Unsaved tabs show a * after their name.

Editing

Cut, copy and paste

Use the Edit menu or the usual shortcuts.

Find / Replace

Press Ctrl+F (Edit > Find / Replace…) to open the Find / Replace dialog. It stays open and follows the tab you are working in.

Go to line

Press Ctrl+G (Edit > Go to Line…) and enter a line number.

Zoom

Use View > Zoom In and Zoom Out, or the toolbar buttons, to change the size of the text in the current editor.

Full screen

Press F11 (View > Toggle Full Screen).

Function outline

The Outline… drop-down in the toolbar lists the functions found in the current file. Select one to jump straight to it. The list refreshes a moment after you stop typing.

Languages and syntax highlighting

Qute chooses the language from the file name when you open a file. To change it, use the Language menu. The current language is shown in the toolbar.

Indentation

Each language has a default indentation policy (tabs or spaces, and a width). The current policy is shown in the status bar as Spaces: 4 or Tab: 4.

  • Mismatch warning: if a file you open uses a different style from your policy, Qute asks whether to convert the file to the current policy.
  • Manual conversion: use Edit > Indentation > Convert to Spaces or Convert to Tabs.
  • Policy settings: the tab width and the “insert spaces” option are in Preferences.

Follow mode

Follow mode works like tail -f: the document is kept up to date as the file grows, which is handy for log files. Start it from File > Open in Follow mode… or the matching toolbar button. Followed files are restored in follow mode the next time Qute starts.

The status bar shows the read/write state of the current tab.

Favorites and recent files

  • Add a favorite: right-click a tab and choose Add to Favorites. The file must be saved first. Files opened in follow mode are remembered as such.
  • Open a favorite: use the Favorites menu.
  • Recent files: File > Open Recent lists the files you opened or saved lately. Files that no longer exist are removed from the list.

Tabs

Click the × on a tab to close it. Right-click a tab for more actions:

Menu itemEffect
Close TabCloses this tab.
Close Other TabsCloses every tab except this one.
Copy File PathCopies the full path of the file to the clipboard.
Add to FavoritesAdds the file to the Favorites menu.
Close All TabsCloses all tabs. It stops if you cancel a “save changes?” prompt.
Close All Output TabsCloses the tabs that hold command output.

Switch tabs with Ctrl+PageDown (next) and Ctrl+PageUp (previous). Hover over a tab to see the full path of its file.

Preferences

Open Settings > Preferences… (or the gear icon in the toolbar). Changes apply to all open tabs.

  • Font: the font and size used in editors.
  • Theme: the color theme of the editor and of syntax highlighting.
  • Tab width: number of columns per indentation level.
  • Insert spaces: use spaces instead of tab characters when you press the Tab key.
  • Minimize to tray: keep Qute running in the system tray when the window is closed.

System tray

With Minimize to tray enabled, closing the window hides Qute instead of quitting. Click the tray icon to bring the window back, or use its menu to quit. If you quit from the tray, Qute still asks about unsaved changes.

Session restore

On exit, Qute saves your window size and position, font, theme, indentation settings, tray option, the recent-files list, and the list of open files with their language and follow-mode state. Unsaved Untitled tabs are not kept. If you start Qute with file names on the command line, those files are opened instead of the previous session.

About and updates

The version in the toolbar looks like vX.<commit count>-<commit hash>. Double-click it to open the About box. Qute checks for updates a couple of seconds after it starts.
